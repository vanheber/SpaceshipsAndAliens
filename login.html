Configuração — Chaves de API para IA

O WARP-Unit usa inteligência artificial generativa para criar missões, planetas, descobertas e narrativas emergentes. Você fornece suas próprias chaves de API — nada fica no servidor.

Gemini (gratuito): aistudio.google.com/apikey
NVIDIA (gratuito): build.nvidia.com

Segurança:

• A chave fica apenas no seu navegador (localStorage), nunca é enviada ao servidor WARP-Unit.

• Gemini: seu navegador chama a Google AI diretamente (?key= na URL, HTTPS). O servidor WARP-Unit não vê a chave.

• NVIDIA: a chave passa pelo proxy local apenas durante a requisição (header X-API-Key) e não é armazenada no servidor.

• Para segurança extra, restrinja sua chave Gemini no Google Cloud Console — ative apenas a API "Generative Language API" e limite por referenciador HTTP (seu-dominio.com/*).
