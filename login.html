SISTEMA OPERACIONAL WARP

Autenticação — Controle de Acesso à IA

O WARP-Unit usa inteligência artificial generativa para criar missões, planetas, descobertas e narrativas emergentes. A IA é servida por APIs externas (Gemini, NVIDIA, Pollinations, Hermes) que consomem créditos ou exigem chaves de API armazenadas no servidor.

A autenticação existe para proteger o uso dessas APIs: apenas usuários autorizados podem gerar conteúdo com IA, evitando consumo abusivo e exposição de chaves.

Como usar: peça a senha de acesso ao administrador do sistema. Ela é definida via a variável de ambiente AUTH_PASSWORD (bcrypt) ou TOTP_SECRET no arquivo .env do servidor. Uma vez autenticado, o navegador armazena um cookie seguro por 30 dias.

O cookie de sessão é httponly, secure e samesite=Lax — não é acessível via JavaScript, apenas enviado nas requisições à API.
