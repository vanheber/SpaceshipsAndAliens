## Findings considered and rejected

- **NVIDIA proxy is public**: intencional, documentado como "gratuito para
  visitantes" no README.
- **Sem package.json/lint/build**: projeto é HTML+CSS+JS Vanilla + PHP, sem
  build tooling — aceito pelo modelo do projeto.
- **Euler angles acumulando em Three.js**: degradação só após centenas de
  roladas, irrelevante pra sessão de jogo típica.
- **Regex greedy `/\{[\s\S]*\}/`**: edge case improvável (IA raramente retorna
  múltiplos JSONs top-level); fix trocaria pra `[\\s\\S]*?\\}` mas o ganho não
  justifica o risco de quebrar parsing atual.
- **Zero testes**: reconhecido (finding #10), excluído por esforço vs. impacto
  imediato — reavaliar quando houver build tooling.
- **Three.js sem dispose**: reinit raro (só page reload), impacto baixo pra
  esforço médio.
- **CSRF no auth**: coberto por `SameSite: Lax` no cookie — por design, não
  auditar de novo.
- **Prompts EN/PT inconsistente**: baixo impacto, adiado — prompts funcionam,
  só desperdiçam tokens.
- **Validação de schema do output da IA**: baixo impacto — fallback local cobre
  falhas de parse.
- **Cookie replay window (30 dias)**: aceito — ferramenta single-user, risco
  baixo.
