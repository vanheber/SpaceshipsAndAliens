WARP-Unit — Sistema de Exploração Interestelar

1. Natureza do Projeto

WARP-Unit é um projeto gratuito, de código aberto, desenvolvido por fãs para uso pessoal e não-comercial. Não há cobrança, assinatura ou monetização de qualquer tipo.

2. Uso do Conteúdo de Star Citizen

WARP-Unit utiliza ativos visuais (imagens de naves, logotipos, conceitos artísticos) do Star Citizen Fankit, disponibilizado publicamente pela Cloud Imperium Games / Roberts Space Industries em robertsspaceindustries.com/fankit. O uso destes ativos segue a política de fandom estabelecida pela RSI:

  • Todo conteúdo de Star Citizen permanece propriedade da Cloud Imperium Rights LLC e Cloud Imperium Rights Limited.
  • WARP-Unit não é afiliado, endossado ou patrocinado pela Cloud Imperium Games ou Roberts Space Industries.
  • Este é um site de fãs não-oficial.

3. Privacidade e Dados

WARP-Unit é uma aplicação estática que roda inteiramente no navegador do usuário. Nenhum dado de jogo é enviado a servidores externos. O estado da campanha é armazenado exclusivamente no armazenamento local do navegador (localStorage/IndexedDB). As comunicações entre dispositivos ocorrem via WebRTC (peer-to-peer), sem passar por servidores intermediários.
